Publish your own clips on schedule, without manual uploads

Clip Autoposter is a desktop tool for Windows. It takes short vertical clips that the owner has edited, and publishes them one part at a time to the owner's own TikTok, YouTube and Instagram accounts at fixed times of the day.

Features

Daily time slots

Up to four publications per day per account, at times the owner chooses (for example 13:30, 15:45, 17:15, 19:30).

Parts in order

Clips are numbered "Part 1, Part 2…". The tool always publishes the next part that is not yet on the account.

No duplicates

Before every run it reads the list of videos already on the account, so a part posted manually or before a restart is never posted twice.

Captions and hashtags

Caption "Series name Part N", the series hashtags and general hashtags are added automatically from a settings file.

Safe recovery

If the computer or the connection fails during an upload, the next run checks the account and either marks the part as published or publishes it again.

One account per series

Each series has its own account on each platform; the owner connects every account once through the platform's official login.

How it works

  1. Prepare clips. The owner puts edited vertical clips (MP4, 9:16) into one folder per series, for example Series name Part 1.mp4.
  2. Connect accounts. For every series and platform the owner signs in once through the platform's official authorization page (TikTok Login Kit, Google OAuth, Instagram Login). The tool keeps only the access token on the owner's computer.
  3. Run on schedule. Windows Task Scheduler starts the tool every 15 minutes. When a time slot comes, the tool publishes the next part to each account.
  4. Check results. Every action is written to a local log file; a status panel shows what was published today, what is next, and any errors.

TikTok integration

Clip Autoposter uses only the official TikTok for Developers APIs:

Product / scopeWhat the tool does with it
Login Kit — user.info.basicThe owner signs in to the TikTok account of a series; the tool shows which account is connected.
Content Posting API, Direct Post — video.publishPublishes the next clip with its caption. Before each post it reads the creator info (allowed privacy levels, posting limits) and respects them.
Content Posting API — video.uploadUploads the video file in chunks as part of the Direct Post flow.
Display API — video.listReads the titles of videos already on the account, so the same part is not published twice.

The tool does not read followers, messages, comments or any data of other users, and posts only to accounts its owner has connected.

FAQ

Who can use Clip Autoposter?

It is a personal tool. It runs on its owner's computer and publishes only to accounts that the owner connected. It is not sold or offered as a hosted service.

Does it change or delete existing videos?

No. It only publishes new clips and reads the titles of existing videos to avoid duplicates.

Where are access tokens stored?

In files on the owner's computer only. See the Privacy Policy for details and how to revoke access.

What if the computer was off at a time slot?

A slot missed by more than 40 minutes is skipped, so clips are never published in a burst.
