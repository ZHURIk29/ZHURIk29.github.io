Privacy Policy — Clip Autoposter

Last updated: October 11, 2026

What the app is

Clip Autoposter is a personal tool used by its owner to upload the owner's own short videos to the owner's own YouTube, TikTok and Instagram accounts. It is not available to the public.

Data the app accesses

  • YouTube (Google): permission to upload videos and to read the list of videos already on the connected channel, so the same video is not uploaded twice.
  • TikTok: basic account info, permission to publish videos and to read the list of the account's videos.
  • Instagram: basic account info and permission to publish Reels, and to read captions of existing posts.

How data is stored and used

Access tokens and the upload log are stored only in files on the owner's computer. They are used only to publish the owner's videos and to check which videos are already published. No data is sold, shared with third parties, used for advertising or transferred to any server other than the official APIs of Google, TikTok and Meta.

YouTube API Services

Clip Autoposter uses YouTube API Services. By using the YouTube features of this app, users agree to be bound by the YouTube Terms of Service. Information obtained through YouTube API Services is handled as described in the Google Privacy Policy.

The app reads only the titles of videos on the connected channel (to avoid duplicate uploads) and uploads the owner's videos. It does not store any YouTube data other than the IDs and titles of videos it uploaded. Stored data is refreshed on every run and deleted within 7 days after access is revoked or on request to the contact address below.

Google API Services

Clip Autoposter's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see also the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time: Google — myaccount.google.com/permissions; TikTok — Settings → Security → Manage app permissions; Instagram — Settings → Apps and websites. Deleting the app's folder on the owner's computer deletes all stored tokens and logs.
