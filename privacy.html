Privacy Policy

Last updated: October 16, 2026

What the app is

Clip Autoposter is a personal desktop tool used by its owner to publish the owner's own short videos to the owner's own TikTok, YouTube and Instagram accounts. It is not offered to the public and does not collect data from other people.

Data the app accesses

  • TikTok: basic profile info of the connected account (user.info.basic), permission to upload and publish videos (video.upload, video.publish) and the list of the account's own videos (video.list), used only to avoid publishing the same part twice.
  • YouTube (Google): permission to upload videos and to read the titles of videos already on the connected channel.
  • Instagram: basic account info, permission to publish Reels, and captions of the account's existing posts.

How data is stored and used

Access tokens and the upload log are stored only in files on the owner's computer. They are used only to publish the owner's videos and to check which videos are already published. No data is sold, shared for advertising, or used for any other purpose.

Services the data is sent to

  • The official APIs of TikTok, Google (YouTube) and Meta (Instagram) — to publish videos and read the owner's video lists.
  • For Instagram only: the Instagram API accepts videos only by a public link, so the video file being published is placed for a short time on the temporary file host litterbox.catbox.moe under a random link that is passed only to Instagram. The host deletes the file automatically after 1 hour. Only the video itself is sent there, never tokens or account data.

YouTube API Services

Clip Autoposter uses YouTube API Services. By using the YouTube features of this app, users agree to be bound by the YouTube Terms of Service. Information obtained through YouTube API Services is handled as described in the Google Privacy Policy. The app does not store any YouTube data other than the IDs and titles of videos it uploaded. Stored data is refreshed on every run and deleted within 7 days after access is revoked or on request to the contact address below.

Google API Services

Clip Autoposter's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time: TikTok — Settings → Security → Manage app permissions; Google — myaccount.google.com/permissions; Instagram — Settings → Apps and websites. Deleting the app's folder on the owner's computer deletes all stored tokens and logs.
